# AstraZeneca Cash Flow Insights & Forecasting 📊

**Datathon 2025 | Team: Data Mavericks**

## Project Overview
This project focuses on analyzing and forecasting AstraZeneca's cash flow using statistical techniques and interactive data visualizations. It aims to identify financial trends, detect unusual transactions, and support effective cash flow and liquidity management.

## Objectives
- Analyze cash inflows, outflows, and overall cash flow trends.
- Forecast short-term and medium-term cash flow.
- Detect unusual cash flow patterns and anomalies.
- Develop an interactive dashboard to support financial decision-making.

## Tools & Technologies
- **Programming & Statistical Analysis:** R
- **Data Visualization:** Power BI
- **Forecasting:** Time-Series Analysis (STLF & ETS)
- **Anomaly Detection:** STL Decomposition and Z-Score Analysis

## Methodology
1. Data preparation and exploratory analysis
2. Cash flow analysis by category, month, and country
3. One-month and six-month cash flow forecasting
4. Anomaly detection using statistical methods
5. Interactive Power BI dashboard development

## Key Findings
- Identified Accounts Receivable (AR) as the primary source of cash inflows.
- Accounts Payable (AP) represented the largest operational cash outflows.
- Detected unusual cash flow spikes in Q2 and sudden declines in Q3.
- Developed a four-page Power BI dashboard for financial monitoring, forecasting, and anomaly detection.
